# 高等教育学生AI工具使用动机影响因素实证研究

基于技术接受模型（TAM），对印尼高等教育学生使用AI学习工具的行为及其影响因素展开的实证分析。课程论文项目，独立完成。

## 项目背景

随着AI工具在高等教育中的应用日益广泛，本研究希望探究：学生对AI工具的**绩效期望**、**使用挑战**、**使用态度**、**AI使用感知**这些因素，究竟如何影响他们**继续使用AI工具的意愿（使用动机）**。

## 数据来源

- 数据集：[Dataset of AI Adoption Usage among Students in Indonesia Higher Education](https://data.mendeley.com/datasets/b89t4x2c2y/1)（Mendeley Data 公开数据集）
- 样本量：605条原始记录，46个变量，经清洗后保留 **534条有效样本**
- 覆盖印尼多所高校、多个专业背景的学生问卷调查数据

## 理论框架

以技术接受模型（TAM）为核心，构建五个变量：

| 变量 | 说明 |
|---|---|
| PE（绩效期望） | 对应感知有用性，学生认为AI工具能否提升学习效率 |
| CU（使用挑战） | 对应感知易用性反向维度，使用AI工具的困难程度 |
| ATU（使用态度） | 学生对AI工具的整体倾向 |
| AUP（AI使用感知） | 学生对AI技术在学习场景中实际效用的认知 |
| MIUA（使用动机） | 因变量，学生继续使用AI工具的意愿 |

## 分析方法与流程

1. **数据预处理**：删除无关字段、分类变量转换、Likert量表（1-4分）异常值处理、缺失值均值填补
2. **信度分析**：Cronbach's Alpha 系数检验问卷内部一致性
3. **描述性统计**：人口统计变量与核心变量分布分析
4. **相关分析**：Pearson相关系数矩阵，探索变量间关联
5. **方差分析**：单因素ANOVA，检验性别对绩效期望是否有显著差异
6. **多元线性回归**：以使用动机为因变量，探究关键影响因素
7. **多重共线性检验**：方差膨胀因子（VIF）验证回归结果可靠性

## 核心结论

- 问卷量表信度良好（PE、ATU、MIUA 的 Cronbach's Alpha > 0.8，CU > 0.7）
- 回归模型解释力达 **55.2%**（R² = 0.552，F = 163，p < 0.001）
- **使用态度（β=0.393）**、**AI使用感知（β=0.344）**、**绩效期望（β=0.236）** 对使用动机具有显著正向影响
- 使用挑战对使用动机的影响不显著
- 性别对AI绩效期望无显著影响（F=2.13，p=0.14）
- 所有自变量VIF值均小于5，回归结果不存在严重多重共线性问题
